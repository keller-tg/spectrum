## Control styles in motion

About 30 seconds each, 1280×800, light mode: hover, press and keyboard focus on
the button matrix; segmented controls (click and arrow keys); answer rows; the
live loading → success button; mode rows; the hero field crosshair.

- [controls-sharp.webm](controls-sharp.webm): square corners, wipe on hover (default)
- [controls-pill.webm](controls-pill.webm): 999px radius on buttons, segments, tags and inputs
- [controls-offset.webm](controls-offset.webm): square, a solid 4px ink offset; hover lifts, press sinks

The recorder writes VP8; the committed files were re-encoded to VP9 (CRF 40)
with Playwright's bundled ffmpeg to keep them near 1 MB each.
